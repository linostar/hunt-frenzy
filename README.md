# Hunt Frenzy

An arcade marsh shooter for desktop and mobile browsers, made with Godot 4.7.1:
shoot geese and special birds over a cartoon marsh while a rival hunter heckles
you and steals the birds you leave flying.

Work in progress. The Godot project lives in `huntfrenzy/`; `tools/validate.sh`
runs the checks and tests, `tools/build_web.sh` builds the web export
(`build/huntfrenzy.zip`).
